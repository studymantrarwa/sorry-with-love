# Sorry with Love keyword map

`500-keyword-map.csv` is a planning sheet containing 500 unique keyword candidates and their suggested destination URL. It is not a report of measured search volumes or a ranking guarantee. The phrases need validation against Google Search Console impressions, Keyword Planner, and actual user behaviour.

## Recommended workflow
1. Deploy the release and verify the sitemap and each landing page returns a successful response.
2. Submit `https://sorry-withlove.vercel.app/sitemap.xml` in Google Search Console.
3. Track query impressions, clicks, CTR, and average position by landing page.
4. Improve pages that earn impressions but low clicks by refining titles and descriptions without clickbait.
5. Add content only when it answers a distinct user question. Do not publish near-duplicate doorway pages to target minor keyword variants.

# SEO content policy — Sorry with Love

This project intentionally does not include a bulk keyword list. Keep content useful to visitors and write for a distinct user need.

- Use search phrases only where they naturally describe the page.
- Do not repeat keyword variants, add hidden text, or create near-identical pages for every phrase.
- Keep the two card-creation landing pages only while they provide distinct value for boyfriend/girlfriend card intent.
- Keep advice in the relevant blog articles instead of creating thin pages for close variants.
- Review Search Console queries and page performance before changing content.
- Indexing depends on the live technical setup and Google's evaluation; no source change guarantees indexing.

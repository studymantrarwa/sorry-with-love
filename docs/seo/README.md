# SEO content policy — Sorry with Love

This project intentionally does not keep a bulk keyword list. The homepage and genuinely useful apology guides cover relevant topics.

- Write for visitors first. Use a phrase only where it accurately describes the page.
- Do not repeat keyword variants, add hidden text, or create near-identical pages for every phrase.
- Keep a landing page only when it serves a distinct user need. The two card-creation pages are for boyfriend/girlfriend card intent.
- Keep detailed advice in relevant blog articles instead of making multiple thin pages for close variants.
- Review real Google Search Console queries and page performance before adding or changing content.
- Keep titles and descriptions specific, readable, and accurate.

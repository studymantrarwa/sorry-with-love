## Avoid ranking-risk tactics
- Google Search does not use the `meta keywords` tag for ranking, so generic repeated keyword lists were removed.
- No competitor-brand keyword stuffing, hidden text, fabricated reviews, fake local addresses, doorway pages or invented social profiles were added.
- The page content is visible to visitors and is intended to answer the query, not just attract clicks.

## After deployment
1. Open Google Search Console for the verified `https://bhavishya-gyani.vercel.app/` property.
2. Submit `https://bhavishya-gyani.vercel.app/sitemap.xml` in **Sitemaps**.
3. Use **URL Inspection** for the home page and the priority tools: `/kundli-form`, `/pdf-kundli`, `/rashi`, `/panchang-muhurat`, `/porutham`, `/tarot`, `/ram-prashnavali`, `/numerology`, and `/astrologers`. Test the live URL first and request indexing when eligible.
4. Monitor **Pages / Indexing**, **Core Web Vitals**, and query impressions. Fix actual crawl or canonical errors shown by Search Console rather than repeatedly resubmitting every URL.
5. Add genuinely useful original articles, real author/editor attribution where appropriate, and real external mentions over time. Rankings and indexing are controlled by search engines and cannot be guaranteed.
